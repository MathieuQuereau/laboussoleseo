Notions de base avec Google Analytics

1 Accroche

Que font les visiteurs une fois sur ton site ?

Imagine que tu possèdes une boutique en ligne. Tu sais combien de personnes passent devant ta vitrine. Tu sais même combien cliquent sur ton résultat dans Google.

Mais une fois arrivées sur ton site, que font-elles ? Consultent-elles tes produits ? Lisent-elles tes articles ? Ajoutent-elles un produit au panier ? Envoient-elles une demande de contact ? C'est une autre partie de l'histoire.

Google Search Console t'aide à comprendre comment les internautes découvrent ton site dans Google. Google Analytics t'aide à étudier ce qu'ils font une fois sur ton site, à partir des données collectées.

Dans ce chapitre, tu vas découvrir les notions essentielles de Google Analytics, sans te perdre dans les dizaines de rapports et d'indicateurs disponibles.

2 Ce que tu vas apprendre

À la fin de ce chapitre, tu sauras :

  • ✓ Comprendre à quoi sert Google Analytics 4
  • ✓ Faire la différence entre un utilisateur, une session et un événement
  • ✓ Identifier les principales sources de trafic
  • ✓ Découvrir les rapports utiles pour un site
  • ✓ Comprendre ce que les visiteurs font sur tes pages
  • ✓ Repérer des pistes d'amélioration à partir des données
  • ✓ Éviter les erreurs d'interprétation les plus fréquentes

3 Le concept expliqué simplement

Google Analytics, c'est quoi ?

Google Analytics 4 (GA4) est un outil d'analyse d'audience qui permet d'étudier les interactions mesurées sur un site Internet ou une application.

Selon la configuration de ton site et les données collectées, tu peux notamment observer :

  • ✓ Le nombre d'utilisateurs
  • ✓ Les sessions
  • ✓ Les pages consultées
  • ✓ Les événements enregistrés
  • ✓ Les sources de trafic
  • ✓ Certaines actions importantes, comme un achat ou l'envoi d'un formulaire lorsqu'elles sont correctement mesurées

Ces informations t'aident à mieux comprendre comment les visiteurs utilisent ton site.

Attention : Google Analytics ne connaît pas automatiquement tous les comportements de tous les internautes. Les résultats dépendent notamment de l'installation de l'outil, de la configuration de la mesure, des choix de consentement et des limites de collecte.

La différence entre utilisateur, session et événement

Ces trois notions sont essentielles pour commencer.

1. L'utilisateur

Un utilisateur correspond à une personne ou à une identité utilisateur estimée par les mécanismes de mesure de Google Analytics.

Le chiffre affiché ne correspond donc pas nécessairement au nombre exact de personnes physiques différentes.

Par exemple, une même personne peut consulter ton site depuis plusieurs appareils et être comptabilisée différemment selon les possibilités d'identification et la configuration.

2. La session

Une session représente une période d'interactions enregistrées sur ton site. Un même utilisateur peut effectuer plusieurs sessions.

Par exemple, une personne consulte ton site le matin, revient le soir et visite à nouveau plusieurs pages. Ces visites peuvent correspondre à plusieurs sessions.

3. L'événement

Dans Google Analytics 4, les interactions sont mesurées sous forme d'événements. Selon la configuration, il peut s'agir :

  • ✓ D'une consultation de page
  • ✓ D'un défilement répondant aux conditions de mesure
  • ✓ D'un clic mesuré
  • ✓ D'une recherche effectuée sur le site
  • ✓ D'un ajout au panier
  • ✓ D'un achat
  • ✓ D'un envoi de formulaire correctement configuré

Un événement correspond donc à une interaction ou à une action enregistrée.

Tous les événements ne représentent pas la même valeur pour ton activité. Une consultation de page et un achat sont deux actions différentes.

💡 Analogie — Le magasin et ses visiteurs — Imagine un magasin physique. L'utilisateur représente une personne qui vient découvrir le magasin. La session représente une visite du magasin. L'événement représente une action observée pendant cette visite, comme entrer dans un rayon ou acheter un produit. Cette analogie reste simplifiée : sur un site Internet, les mécanismes de mesure ne permettent pas toujours d'identifier les personnes de manière exacte. Mais elle permet de comprendre la différence entre ces trois notions.

Les sources de trafic : d'où viennent les visiteurs ?

Google Analytics peut également t'aider à comprendre comment les visiteurs arrivent sur ton site. Selon les données disponibles, tu peux retrouver plusieurs catégories de trafic.

Organic Search — Il s'agit du trafic provenant des résultats naturels des moteurs de recherche. Par exemple, une personne recherche « comment choisir un ordinateur portable », clique sur un résultat non sponsorisé et arrive sur ton site.

Direct — Cette catégorie regroupe les visites pour lesquelles Google Analytics ne dispose pas d'informations suffisantes pour identifier une autre source. Elle ne signifie donc pas toujours que l'utilisateur a tapé directement ton adresse dans son navigateur.

Referral — Il s'agit généralement du trafic provenant d'un lien placé sur un autre site. Par exemple, un blog parle de ton entreprise et un lecteur clique sur le lien vers ton site.

Organic Social — Cette catégorie peut regrouper du trafic provenant de publications naturelles sur des réseaux sociaux, lorsque les informations disponibles permettent de le classer ainsi.

Paid Search — Cette catégorie correspond au trafic issu des annonces payantes sur les moteurs de recherche, lorsque les visites sont correctement identifiées.

Ces catégories te permettent de mieux comprendre les différents chemins qui conduisent les visiteurs jusqu'à ton site.

Les pages consultées et les interactions

Tu peux également examiner les pages que les visiteurs consultent. Cela permet de repérer :

  • ✓ Les contenus les plus consultés
  • ✓ Les pages qui attirent l'attention
  • ✓ Les pages qui participent à un parcours utilisateur
  • ✓ Les contenus qui semblent peu consultés
  • ✓ Les pages associées à des actions importantes, si celles-ci sont mesurées

Attention toutefois : une page très consultée n'est pas automatiquement une page performante. Tout dépend de son objectif.

Un article informatif peut avoir pour objectif de répondre à une question. Une page de contact doit plutôt faciliter une prise de contact.

Les conversions : quand une visite devient utile pour ton activité

Une conversion correspond à une action importante pour ton activité, que tu as choisi de mesurer. Selon ton site, il peut s'agir : d'un achat, d'une demande de devis, d'un envoi de formulaire, d'une inscription, d'une prise de rendez-vous.

Dans GA4, les événements importants peuvent être marqués comme événements clés.

Il faut donc configurer correctement la mesure pour que ces actions soient enregistrées de manière fiable.

Google Analytics ne remplace pas Google Search Console

Les deux outils sont complémentaires.

Google Search ConsoleGoogle Analytics
Mesure notamment les impressions et les clics dans Google SearchMesure les interactions enregistrées sur le site
Aide à analyser les requêtes de rechercheAide à analyser les sources de trafic et les comportements
Permet d'étudier la visibilité des pages dans GooglePermet d'étudier les pages consultées et les événements
Aide à identifier certaines questions liées à l'indexationAide à comprendre les parcours et les actions mesurées

Il est normal que les chiffres ne correspondent pas exactement.

Les outils n'ont pas le même périmètre, les mêmes règles de collecte ni nécessairement les mêmes données disponibles.

⚠️ Les pièges à éviter :

  • ✗ Confondre utilisateurs et sessions
  • ✗ Penser que chaque événement représente une personne différente
  • ✗ Croire que Google Analytics identifie parfaitement tous les visiteurs
  • ✗ Considérer le trafic direct comme exclusivement composé de personnes ayant tapé l'adresse du site
  • ✗ Penser qu'une page très consultée atteint nécessairement son objectif
  • ✗ Interpréter les données sans vérifier la configuration de la mesure
  • ✗ Comparer directement les chiffres de Search Console et d'Analytics sans tenir compte de leurs différences

4 Exemple concret

Tu possèdes un site qui propose des conseils SEO et une formation pour débutants. Tu publies un article : Comment choisir ses premiers mots-clés SEO ?

Tu consultes Google Search Console et tu constates que cet article reçoit des clics depuis Google. Tu ouvres ensuite Google Analytics.

Tu peux y examiner, selon les données collectées :

  • ✓ Le trafic associé à la recherche naturelle
  • ✓ Les consultations de l'article
  • ✓ Les autres pages consultées pendant les visites
  • ✓ Les interactions mesurées
  • ✓ Les inscriptions à ta newsletter, si elles sont correctement suivies

Imaginons que ton article attire beaucoup de visiteurs, mais que peu d'entre eux consultent la page de ta formation.

Tu ne peux pas conclure immédiatement que l'article est mauvais. Il faut d'abord vérifier son objectif.

Peut-être que les lecteurs viennent simplement chercher une réponse rapide. Peut-être que le lien vers la formation est difficile à repérer. Peut-être encore que l'article répond parfaitement à la question, mais que la proposition de formation n'est pas adaptée à leur besoin.

Google Analytics peut t'aider à approfondir ces questions, à condition de disposer de données correctement collectées et de ne pas tirer de conclusions trop rapides.

5 Comment le mettre en pratique

1

Accède à Google Analytics

Connecte-toi à Google Analytics avec ton compte Google. Si tu n'as pas encore configuré ton site, tu devras créer une propriété GA4 et suivre les étapes proposées pour installer et configurer la collecte des données. L'installation peut passer par une balise Google, Google Tag Manager ou une intégration proposée par ton système de gestion de contenu. La méthode dépend de ton site et de sa configuration. Si tu utilises un outil de gestion du consentement, vérifie également que la collecte respecte les choix des visiteurs et les exigences applicables à ton site.

2

Vérifie que les données sont bien collectées

Avant d'interpréter les chiffres, vérifie que la mesure fonctionne. Tu peux notamment consulter les rapports en temps réel et effectuer une visite de test pour vérifier si les interactions attendues sont enregistrées. Attention : les résultats peuvent dépendre de la configuration, du consentement et des mécanismes de collecte. Une absence de données ne signifie donc pas systématiquement que personne n'a visité le site.

3

Découvre le rapport d'acquisition

Commence par explorer les rapports d'acquisition. Ils permettent notamment d'étudier comment les utilisateurs ou les sessions arrivent sur ton site, selon le rapport consulté et la dimension choisie. Tu peux examiner la part du trafic provenant de la recherche naturelle, des réseaux sociaux, des sites référents ou d'autres sources disponibles. Demande-toi si les canaux qui t'apportent des visiteurs correspondent à tes objectifs.

4

Explore les pages consultées

Consulte le rapport consacré aux pages et aux écrans, ou les rapports équivalents disponibles dans ton interface. Repère les contenus qui attirent l'attention. Compare les pages en tenant compte de leur objectif : un article de blog, une fiche produit et une page de contact ne remplissent pas la même fonction.

5

Observe les interactions

Regarde les événements enregistrés. Tu peux commencer par comprendre les événements de consultation de page, puis examiner les interactions pertinentes pour ton activité. Si tu souhaites suivre une inscription, un achat ou un envoi de formulaire, vérifie que l'action est correctement mesurée. Ne suppose pas qu'un événement spécifique existe automatiquement : certains événements nécessitent une configuration supplémentaire.

6

Définis une action importante

Choisis une action qui compte réellement pour ton site. Par exemple : pour un site vitrine, une demande de contact ; pour une boutique en ligne, un achat ; pour un site de formation, une inscription ; pour un média, une consultation de contenu ou une inscription à une newsletter. Vérifie ensuite que cette action est correctement mesurée et, si nécessaire, configurée comme événement clé.

7

Formule une question et prends une décision

Évite de regarder tous les indicateurs en même temps. Choisis plutôt une question précise. Par exemple : « Les visiteurs qui arrivent depuis Google consultent-ils également mes pages de services ? » Examine les données disponibles, formule une hypothèse et cherche une action adaptée. Tu peux ensuite suivre l'évolution pour voir si les changements observés correspondent à tes attentes.

💡

À retenir : Google Analytics est utile lorsqu'il répond à une question concrète sur ton audience ou ton activité. Il ne s'agit pas d'accumuler les rapports, mais de comprendre les comportements mesurés pour améliorer ton site.

Question 1/4

Question 1 — À quoi sert principalement Google Analytics ?

A À mesurer uniquement les positions des mots-clés
B À étudier les interactions mesurées sur un site ou une application
C À remplacer Google Search Console
D À créer automatiquement des backlinks
💡 Bonne réponse : B. Google Analytics permet d'étudier les interactions enregistrées, les sources de trafic et les comportements mesurés sur le site.

Question 2 — Quelle est la différence entre un utilisateur et une session ?

A Un utilisateur correspond à une identité estimée, tandis qu'une session correspond à une période d'interactions
B Une session correspond toujours à une personne différente
C Les deux termes désignent exactement la même chose
D Un utilisateur correspond uniquement à un achat
💡 Bonne réponse : A. Un même utilisateur peut effectuer plusieurs sessions, et la mesure ne correspond pas nécessairement au nombre exact de personnes physiques.

Question 3 — Que signifie généralement la catégorie Organic Search ?

A Le trafic issu des annonces payantes
B Le trafic provenant des résultats naturels des moteurs de recherche
C Le trafic provenant uniquement des réseaux sociaux
D Le trafic généré par les newsletters
💡 Bonne réponse : B. Organic Search désigne le trafic issu des résultats naturels des moteurs de recherche lorsque la source est correctement identifiée.

Question 4 — Pourquoi faut-il configurer correctement les événements importants ?

A Pour garantir automatiquement une hausse du trafic
B Pour mesurer les actions importantes pour l'activité
C Pour remplacer les contenus du site
D Pour améliorer automatiquement les positions dans Google
💡 Bonne réponse : B. Les événements doivent être correctement mesurés pour analyser des actions comme les achats, les inscriptions ou les demandes de contact.

8 Et après ?

La suite logique

Tu viens de découvrir les bases de Google Analytics et la manière dont cet outil complète Google Search Console.

Tu peux maintenant distinguer trois étapes importantes :

  • La visibilité : tes contenus apparaissent-ils dans Google ?
  • L'acquisition : comment les visiteurs arrivent-ils sur ton site ?
  • Les interactions : que font-ils une fois sur tes pages ?

Ces trois dimensions t'aident à mieux comprendre les performances de ton site.

Mais garde une règle en tête : un chiffre n'est utile que si tu sais quelle question il permet d'éclairer.

Tu n'as pas besoin de maîtriser tous les rapports dès le départ. Commence par quelques indicateurs, vérifie que les données sont fiables et utilise-les pour prendre des décisions progressives.
